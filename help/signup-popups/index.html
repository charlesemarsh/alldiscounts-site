Sign-up popups

Show a popup that asks shoppers for their email address. Each sign-up is added to your Shopify customers as subscribed to email marketing, and you can thank them with a discount code or a free gift.

Set it up

  1. In the app, go to Discount Campaigns and click Create a campaign.
  2. On the Subscription popup card, click Create.
  3. Enter a Campaign name. Only you see it.
  4. Under When to show the popup, set the Delay (seconds) and the Cooldown (days).
  5. Under Popup content, write the Heading, Body and Primary button label. You can add an Image URL (optional) and a terms link with Terms link text (optional) and Terms link URL. You need a heading or a body.
  6. Under Reward after email signup, choose a reward (see below).
  7. Optionally set a Schedule.
  8. Click Create popup.

The popup goes live as soon as you create it. It runs through the All Discounts & Promotions app embed, so the embed must be turned on in your theme.

Where the emails go

Each new email address is added to your Shopify customers, with email marketing set to subscribed (single opt-in). You’ll find them under Customers in your Shopify admin, ready for any email tool that uses your Shopify customer list.

If the email already belongs to a customer, the app leaves that customer as they are. Their email marketing setting isn’t changed.

Rewards

RewardWhat happens after sign-up
No reward — just collect emailsThe popup shows a thank-you message.
Reveal a discount codeThe popup shows your Discount code and an optional Success message. If you leave the message blank, it says “Use code CODE at checkout.”
Free gift — auto-add or let the customer chooseThe gift goes straight into the cart at no charge. Set Number of free gifts and pick the gift variants. If you pick more variants than the number of gifts, the shopper chooses from them.

The app doesn’t create the code for Reveal a discount code. Set it up first, in this app or in Shopify, or the code won’t work at checkout.

For free gifts, the app creates the discount that makes the gift free, so there’s nothing else to set up. Each email address can claim the gift once. After an order has used it, the same email can’t claim it again.

What shoppers see

  • The popup appears once the shopper has been on a page for the delay you set. The delay starts again on each new page.
  • If the shopper closes the popup or signs up, it stays hidden for the number of days in Cooldown (days). This is remembered in their browser.
  • If another popup from the app is already open, the sign-up popup doesn’t show on that page.
  • If you have more than one sign-up popup live, shoppers see one at a time.

Good to know

  • The popup has no status setting. To stop it, select it in Discount Campaigns and click Pause, set an end date under Schedule, or delete it.
  • A cooldown of 0 means the popup can show again on the next page load after it’s closed.
