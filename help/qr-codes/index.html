QR codes

Print a QR code on packaging, flyers or signs. Shoppers who scan it land on the page you choose with your discount already applied.

How it works

Each QR code holds a link to a page of your store with a unique code on the end, like yourstore.com/?qr=…. When a shopper scans it, the app recognises the code and applies your discount. The discount stays with their cart as they browse and go to checkout. Nobody has to type a code.

The ending is a long random value the app creates for you, so people can’t guess it. In Shopify the discount is an automatic discount, named after your QR code.

QR codes need the app’s theme embed switched on. See Getting started if you haven’t done that yet.

Set it up

  1. In the app, open Discount Campaigns and click Create a campaign.
  2. Find QR code and click Create.
  3. Under QR code details, enter an Internal name and set Status to Active when you’re ready for it to work. Draft and Paused codes don’t apply a discount.
  4. Under Destination URL, choose where scanning takes people (see below).
  5. Style the code under QR code design and click Download PNG.
  6. Set up the discount in one or more of Product discounts, Order discounts and Shipping discounts. At least one needs a value above zero.
  7. Optionally, fill in Short URL (optional), Popup experience (optional), Combinations, Usage limits and Schedule.
  8. Click Save in the save bar at the top of the page.

After saving, click Preview for testing to open your store with the popup forced to show, even if you dismissed it earlier. Scan the code with your phone to test it properly before you print.

Destinations

Pick a Destination type:

  • Homepage
  • Product page: enter the Product handle, the last part of the product’s address (yourstore.com/products/handle).
  • Collection page: enter the Collection handle in the same way.
  • Cart
  • Custom path: any page on your store, starting with /, such as /pages/summer-sale.

The Landing URL preview shows the full address. The same address appears under QR code design as the QR code URL, which is exactly what the code contains. It uses your store’s main domain.

Changing the destination changes the address inside the code, so download and print it again. Codes you’ve already printed keep opening the old page.

Design options

The preview under QR code design updates as you change:

  • Foreground color and Background color. Keep strong contrast (dark on light) so phones can read it.
  • Corner style: Square or Rounded.
  • Logo image URL (optional): a logo in the middle of the code. A square image hosted on Shopify’s CDN works best.
  • Show frame with text: adds a bar under the code with your Frame text (for example “Scan for discount”) in your chosen Frame color.

Download PNG saves the code with its frame as an image you can add to flyers, packaging or signs.

Short URLs

Enter a Short URL path such as /go/scan to get a short address like yourstore.com/go/scan, which goes to the same page with the same discount. Print it next to the code for people who’d rather type, or use it in an SMS or social bio. The app adds it to your store as a Shopify URL redirect. The path must start with / and can’t contain spaces or a ?. If the redirect can’t be created, for example because the path is already used, the QR code still saves and a Short URL issue banner explains why.

What shoppers see

Tick Show popup when the QR code is scanned to greet people as they arrive, with your own heading, text, buttons, image and terms link. Without a popup, the discount simply shows up in the cart and at checkout. Product discounts can also be a Free gift, which is added to the cart or offered in a popup.

Limits and scheduling

  • Maximum redemptions: the most orders that can use this QR code. Once it’s reached, scanning no longer applies the discount.
  • Schedule: choose Run this rule continuously or Run this rule for a specific time period. Outside those dates, scanning still opens your store but doesn’t apply the discount.
  • To stop a QR code for now, set Status to Paused.

See how it’s doing

Open Analytics to see revenue, orders and average order value for each QR code. Click a QR code to see sales by product and each order.
