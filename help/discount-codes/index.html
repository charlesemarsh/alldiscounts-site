Advanced discount codes

An advanced discount code lets one code do several things at once: take money off products, off the whole order and off shipping. Shoppers enter it at checkout.

Set it up

  1. In the app, go to Discount Campaigns and click Create a campaign.
  2. Find Advanced discount code and click Create.
  3. Enter a Campaign name (only you see it) and the Discount code, or click Generate random code. Codes are saved in capitals.
  4. Switch on each part you want: Product discounts, Order discounts and Shipping discounts. You need at least one. Product discounts is on when you start.
  5. Fill in each part you switched on (see below).
  6. Check Combinations, Customer selection and Schedule, then click Create discount code.

The Summary on the right lists the parts the code includes as you build it.

Product discounts

  • Product discount type: Percentage, Fixed amount, Free gift or Each variant’s own %.
  • Minimum requirements: none, a Minimum cart total or a Minimum quantity of items. With a minimum set, you can choose collections whose products don’t count towards it, such as sale items.
  • Applies to: Products and variants, Collections, Vendors or Product types.
  • Discount message (optional): the text shoppers see next to the discount. Leave it blank for the default, such as “20% OFF”.

With Free gift, you pick the gift products or a collection, and how the shopper gets it: Manual, Manual - Show popup or Auto add to cart.

Each variant’s own %

Use this when different variants need different discounts, for example 10% off one colour and 30% off another, under a single code.

  1. In Shopify, store each variant’s percentage in a variant metafield, for example custom.discount_percent. A number field or text such as 15 or 15% works.
  2. In the product discount, choose Each variant’s own % and enter the metafield as namespace.key in Variant metafield.
  3. Set Applies to as usual. Only matching variants that have a value get the discount.

Variants with no value, zero or a value over 100 aren’t discounted. Each discounted line shows its own percentage, such as “15% OFF”, unless you set a discount message.

Order discounts

  • Order discount type: Percentage or Fixed amount off the order.
  • An optional minimum cart total or quantity. With a minimum cart total, switch on Exclude collections from cart total to leave some collections out of the count.
  • An optional discount message. The default looks like “10% OFF ORDER”.

Shipping discounts

  • Shipping discount type: Percentage, Fixed amount or Free shipping.
  • An optional minimum cart total or quantity. With a minimum cart total, tick Count the minimum after this code’s product discount if the cart has to reach the minimum once the code’s product discount is taken off.
  • Only these shipping rates: rate names exactly as shoppers see them at checkout, separated by commas, for example Standard. Only those rates are discounted. Leave it blank for every rate.

What shoppers see

Shoppers enter the code at checkout. Each part that applies shows against the products, the order total or the delivery cost.

Good to know

  • Thresholds and fixed amounts are in your store currency and converted for shoppers paying in another currency.
  • Use Combinations to decide which other discounts this code can stack with. If a live discount won’t stack with it, the form tells you which one.
  • For a code that only discounts shipping, with a choice of countries, a shipping discount is simpler.
  • Customer selection is All customers for now; customer segments are marked as coming soon.
