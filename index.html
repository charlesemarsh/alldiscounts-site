Questions

Which themes does it work with?

Any Online Store 2.0 theme. You switch the app on in the theme editor and add the blocks you want, such as the tier picker or the cart progress bar. If you’d like a hand placing them, email us and we’ll do it for free.

Do shoppers need to enter a code?

No. Tiers, bundles, Buy X Get Y, cart goals and free gifts apply automatically at checkout. You can still create discount codes when you want one.

What happens to a bulk sale if I uninstall?

End any running sale first, so the app can put your prices back. If you uninstall without ending it, each discounted variant still holds its original price in a metafield called behaviour_discounts.original_price, which you can see in the Shopify admin and use to set the prices back.

Can I try it before paying?

Yes. The free plan covers 10 discounted orders a month, and Pro and Plus both start with a 7-day free trial.
